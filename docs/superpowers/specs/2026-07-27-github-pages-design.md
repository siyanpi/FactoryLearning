# GitHub Pages 发布设计

## 目标

将现有功能性食品工厂生产场景学习网站发布为 GitHub Pages，供同事通过浏览器直接访问。

目标访问地址：

`https://siyanpi.github.io/FactoryLearning/`

## 已确认方案

- 将现有仓库 `siyanpi/FactoryLearning` 从私有改为公开。
- 保留当前网站源代码和现有线上版本。
- 新增独立的静态网页构建入口，不改动课程内容、答题逻辑和本地进度保存方式。
- 通过 GitHub Actions 自动构建并发布 GitHub Pages。
- 后续推送到默认分支时，自动更新 GitHub Pages。

## 技术设计

### 静态网页入口

新增 GitHub Pages 专用入口，复用现有学习应用、课程数据、样式和进度管理模块。

静态构建使用仓库子路径 `/FactoryLearning/` 作为资源基础路径，避免脚本和样式在 GitHub Pages 上出现路径错误。

### 自动发布

新增 GitHub Actions 工作流：

1. 读取仓库代码。
2. 安装锁定版本的依赖。
3. 运行课程数据与进度测试。
4. 检查用户可见文案中的禁用英文缩写。
5. 生成静态网页文件。
6. 上传并发布到 GitHub Pages。

### 数据与隐私

- 网站不设置服务器数据库。
- 不收集姓名、邮箱、答题记录或其他个人信息。
- 每位学习者的进度仅保存在其当前浏览器中。
- 清理浏览器数据或更换设备后，学习进度不会自动迁移。
- 仓库公开后，源代码、课程内容、提交历史和自动发布记录均可被任何人查看。

## 异常处理

- 构建、测试或文案检查失败时，不发布新版本。
- 旧的成功版本继续在线，不受失败任务影响。
- 若 GitHub Pages 首次启用失败，先检查仓库 Pages 来源和工作流权限，不改动课程内容。

## 验收标准

- GitHub 仓库显示为公开。
- 默认分支为 `main`。
- GitHub Pages 发布任务成功。
- `https://siyanpi.github.io/FactoryLearning/` 可以打开。
- 首页样式、六个学习单元、综合关卡和本地进度保存功能正常。
- 自动测试全部通过。
- 用户可见文案未出现禁用英文缩写。
