# 功能性食品工厂生产场景学习

一个面向科研、产品、质量、采购和项目团队的场景学习网站。

## 团队访问

学习网站：

https://siyanpi.github.io/FactoryLearning/

同事使用浏览器打开即可，无需安装。每个人的学习进度独立保存在当前浏览器中；清理浏览器数据或更换设备后，进度不会自动迁移。

## 学习内容

- 生产路线选择
- 发酵放大
- 酶解控制
- 膜分离选型
- 干燥工艺决策
- 工厂与供应商评审
- 综合供应商评审关卡

每个基础单元约 15 分钟，学习进度保存在当前设备。

## 本地运行

```bash
npm install
npm run dev
```

## 验证

```bash
npm test
npm run verify:copy
npm run build
```

## GitHub Pages 验证

```bash
npm run verify:pages
```
